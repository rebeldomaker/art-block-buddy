## Art Block Buddy
A simple, small terminal program to aid in artists struggling with art block. This was made as I had a need for such aid, since I am an artist myself.

## Getting started

PLEASE carefully read this guide FIRST before making bug reports to the developer, thank you! This may sometimes work out of the box for some MacOS or Linux users, but ensure to read this first regardless.

### Installing dependencies
You will need to install required dependencies that this script relies on, in order to ensure this program can run in the first place.
This program has to be run thru a terminal. In your terminal of choice, type the following:

`sudo apt install python3` for Ubuntu or Debian GNU/Linux

`doas apt install python3` for *BSD OSes

`brew install python3` for MacOS

`winget install python3` for Windows 10 
_note: has not yet been tested on Windows 11 but should in theory work the same for both_

### Where to find your terminal
Assuming you are not too proficient in IT or tech...

for Windows users
In the start menu, type CMD for Windows, and then run the terminal program. Albeit I personally use Tabby as my default terminal for that OS.

for MacOS users
open finder
go to Applications
Open the Utilities folder
run the Terminal.app found within that location

for Debian based Linux users
ctrl + alt + t

## Usage
for Linux or MacOS, change directory to the folder where you downloaded the main.py file into
`cd ~/Downloads/`

Then run the script file
`python3 main.py`

_Tip: you can just type part of the command into terminal, then press TAB to autocomplete_
